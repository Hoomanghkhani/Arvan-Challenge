# پلاگین فروشگاه ابری آروان‌کلاد (ArvanCloud WordPress Reseller Plugin)

پلاگین رسمی و مستقل وردپرس برای فروش و نمایندگی محصولات ابری **آروان‌کلاد** بر مبنای دیزاین‌سیستم **سرخاب (Sorkhab Design System)**.

---

## 🌟 ویژگی‌های کلیدی

- **استقلال کامل (Zero-Dependency):** بدون وابستگی به ووکامرس، المنتور، قالب‌ها یا افزونه‌های دیگر.
- **محصولات سه‌گانه:**
  - ☁️ **سرور ابری (ECC - ابرک):** انتخاب منطقه و دیتاسنتر (فروغی، شهریار، زاینده‌رود)، سیستم‌عامل، پلن‌های پردازشی (Flavors) و اسلایدر دیسک SSD NVMe.
  - 🌐 **شبکه توزیع محتوا (CDN):** ثبت دامنه، سطوح خدمات (پایه، رشد، سازمانی)، فعال‌سازی SSL رایگان و WAF لبه.
  - 🗄️ **فضای ذخیره‌سازی شیء (Object Storage - S3):** ساخت باکت، دیتاسنترهای سیمین و شهریار، کنترل دسترسی خصوصی/عمومی و اسلایدر حجم.
- **دیزاین‌سیستم رسمی سرخاب (Sorkhab):**
  - رنگ سازمانی سرخابی آروان (`#FF0066`).
  - کامپوننت‌های ArButton، ArTab، ArBadge، ArCard، ArToast و ArModal.
  - ریسپانسیو کامل دسکتاپ و موبایل با تب‌های اسکرول‌شونده و نوار چسبان پرداخت (Sticky Bottom Bar).
- **قیمت‌گذاری مصرف واقعی (Pay-As-You-Go):** محاسبه آنلاین هزینه ساعتی و تخمین ماهانه.
- **قوانین قطع سرویس (Service Termination Policy):**
  - کسر خودکار هزینه ساعتی از کیف پول توسط WP-Cron.
  - تعلیق و خاموش شدن سرویس در صورت منفی شدن موجودی.
  - حذف خودکار (Terminate) پس از ۲۴ ساعت در صورت عدم تسویه.
  - فعال‌سازی مجدد و روشن شدن خودکار سرویس‌ها به محض شارژ کیف پول.
- **پیشخوان ادمین پیشرفته:**
  - شاخص‌های کلیدی عملکرد (KPI) و تخمین درآمد ماهانه.
  - اجرای دستی چرخه کسر هزینه ساعتی (Billing Runner).
  - کنترل عملیاتی کامل سرویس‌ها: ⚡ خاموش، ⚡ روشن، 🔄 ری‌استارت و 🗑️ حذف دائم.
  - ابزار شارژ و مدیریت موجودی کیف پول کاربران توسط ادمین.

## 📁 ساختار پروژه

```
arvan-store/
├── arvan-store.php             # فایل اصلی پلاگین، تعریف جداول دیتابیس و هوک‌های راه‌اندازی
├── includes/
│   ├── admin-settings.php      # پیشخوان ادمین، تنظیمات API و کنترل عملیاتی منابع
│   ├── auth.php                # اعتبارسنجی توکن دسترسی نماینده
│   ├── cron.php                # چرخه کران‌جاب کسر هزینه ساعتی و قوانین تعلیق/حذف
│   ├── post-types.php          # تعاریف ساختارهای داده
│   ├── rest-api.php            # اندپوئینت‌های REST API کیف پول، سفارشات و مدیریت سرویس
│   └── shortcode.php           # شورت‌کد [arvan_store] و قالب تمام‌صفحه مستقل (?standalone=1)
└── frontend/
    └── app.js                  # اپلیکیشن فرانت‌اند Vue 3 با دیزاین‌سیستم سرخاب
```

## 🚀 نحوه نصب و راه‌اندازی

1. پوشه `arvan-store` یا فایل `arvan-store.zip` را در مسیر `wp-content/plugins/` وردپرس کپی کنید.
2. از بخش **افزونه‌ها** در پیشخوان وردپرس، افزونه **«فروشگاه محصولات ابری آروان‌کلاد»** را فعال کنید.
3. در منوی مدیریت وردپرس وارد بخش **فروشگاه آروان > تنظیمات** شوید و کلید API و توکن دسترسی را وارد نمایید.
4. برگه‌های پیش‌ساخته به صورت خودکار ایجاد می‌شوند:
   - فروشگاه مستقل: `http://your-site/arvan-store/?standalone=1`
   - فروشگاه در قالب سایت: `http://your-site/arvan-store/`

## 🛠 اندپوئینت‌های REST API

| متد | آدرس اندپوئینت | توضیحات |
| :--- | :--- | :--- |
| `GET` | `/wp-json/arvan-store/v1/wallet/balance` | دریافت موجودی، نرخ مصرف ساعتی و تخمین پایداری |
| `POST` | `/wp-json/arvan-store/v1/wallet/charge` | شارژ اعتبار کیف پول کاربر |
| `POST` | `/wp-json/arvan-store/v1/order` | ثبت سفارش و ساخت سرور ابری، CDN یا باکت S3 |
| `GET` | `/wp-json/arvan-store/v1/services` | لیست سرویس‌های ابری مشتری |
| `POST` | `/wp-json/arvan-store/v1/service/action` | عملیات روی سرویس (خاموش، روشن، ری‌استارت، حذف) |
